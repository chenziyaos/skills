# Ouro — Host-Side Minimal Write Checklist

## Before the run
- [ ] Pick `L5` as the first case
- [ ] Confirm a stable `asset_id`
- [ ] Confirm inventory evidence is available
- [ ] Open the runtime result skeleton
- [ ] Open the governance artifact template

## During the run
- [ ] Record the five-way primary decision first
- [ ] Record governance signal only if surfaced
- [ ] Record evidence maturity
- [ ] Record inventory evidence presence
- [ ] Record evidence basis

## Before emitting the artifact
- [ ] `Governance Signal != null`
- [ ] Evidence envelope is complete
- [ ] Advisory wording is preserved
- [ ] `asset_id` and `run_id` are known

## After emitting the artifact
- [ ] Link runtime result and artifact
- [ ] Confirm readers will not confuse signal with lifecycle fact
- [ ] Confirm no strong merge/deprecate/retire wording slipped in
