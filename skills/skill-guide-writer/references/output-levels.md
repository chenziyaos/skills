# skill-guide-writer — Output Levels

## 默认策略

- 未指定层级：输出 **L2 + L3**
- 用户说“简短 / 概要 / one-pager”：输出 **L1**
- 用户说“完整 / 详细 / developer reference”：输出 **L2 + L3 + L4**

## L1 — One-pager

适合决策者或第一次了解能力的人：
- 一句话价值主张
- 3 个典型场景
- 1 个最短示例
- 与替代方案的差异

## L2 — Quick Start

适合第一次上手：
- 前置条件（权限 / 配置 / 依赖）
- 从零到第一次成功调用的最短路径
- 一个端到端示例
- 常见首次错误与修复

## L3 — Full Guide

适合日常用户：
- 功能分模块说明
- 每个模块至少 1 个可复制示例
- 参数说明表
- 触发条件 / 使用边界
- FAQ / known limits / 与其他技能的协作关系

## L4 — Developer Reference

适合二次开发或维护者：
- 内部结构概览
- 扩展点与自定义方式
- 稳定契约 / 数据流
- 版本变化与 breaking changes
