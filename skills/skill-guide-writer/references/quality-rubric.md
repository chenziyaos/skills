# skill-guide-writer — Quality Rubric

## 覆盖度

- [ ] 是否说明了适用对象与前置条件？
- [ ] 是否至少提供了一个最短成功路径？
- [ ] 是否覆盖了关键参数或关键输入？
- [ ] 是否解释了与相邻技能/工具的边界？

## 可操作性

- [ ] 示例是否可直接复制，且不依赖隐含上下文？
- [ ] 示例参数是否贴近真实场景，而不是 `foo/bar/test`？
- [ ] 错误修复步骤是否具体到“下一步做什么”？

## 一致性

- [ ] 触发词、参数名、输出字段是否与现有文件一致？
- [ ] 文中是否混淆了“事实”和“推断”？
- [ ] 是否避免承诺当前未验证的能力？

## 增量更新

- [ ] `[NEW]` / `[CHANGED]` / `[DEPRECATED]` 标记是否只用于真的变化？
- [ ] 更新后的全文是否仍然可独立阅读，而不是依赖旧版上下文？
